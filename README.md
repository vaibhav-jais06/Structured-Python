## 📖 About The Project

Welcome to the **Structured-Python** repository! Whether you are writing your first line of code or brushing up on the basics, this project provides a structured, easy-to-follow, and interactive approach to learning Python.

<details>
  <summary><strong>Click to see what's inside!</strong></summary>
  
  Currently, the repository features `Python Intro.ipynb` - a comprehensive Jupyter Notebook covering:
  - 🖨️ **Warm-up & Basic Printing:** Mastering the `print()` function.
  - 🔢 **Literals & Data Types:** Integers, floats, strings, and booleans.
  - 📦 **Variables:** Declaring and manipulating variables in memory.
  - ⌨️ **User Input:** Interacting dynamically with users via `input()`.
  - ⚙️ **Functions:** Defining custom logic, passing arguments, and modularizing code.
</details>

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites
Make sure you have Python and Jupyter installed.
```bash
# Install jupyter notebook via pip
pip install notebook
```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vaibhav-jais06/Structured-Python.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd Structured-Python
   ```
3. **Launch Jupyter:**
   ```bash
   jupyter notebook
   ```
   > 💡 **Tip:** Once Jupyter opens in your browser, click on `Python Intro.ipynb` to start learning!

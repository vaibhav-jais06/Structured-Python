# Structured-Python

Welcome to the **Structured-Python** repository! This project contains foundational python learning resources designed to help beginners grasp the basics of Python programming in a structured and intuitive way.

## 🚀 Contents

Currently, the repository features:

### 1. `Python Intro.ipynb`
A comprehensive Jupyter Notebook covering essential Python concepts, including:
- **Warm-up & Basic Printing:** Introduction to the `print()` function and output formatting.
- **Literals & Data Types:** Understanding integers, floats, strings, and booleans.
- **Variables:** Declaring and using variables in Python.
- **User Input:** Interacting with users using the `input()` function.
- **Functions:** Defining custom functions, passing parameters, and using default arguments.

## 🛠️ Getting Started

To explore the notebook, you can either:
- Open it directly on [GitHub](https://github.com/vaibhav-jais06/Structured-Python).
- Run it locally using Jupyter Notebook or JupyterLab.
- Import it into [Google Colab](https://colab.research.google.com/) for a cloud-based interactive experience.

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/vaibhav-jais06/Structured-Python.git
   ```
2. Navigate to the directory:
   ```bash
   cd Structured-Python
   ```
3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

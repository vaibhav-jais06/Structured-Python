## 🗂️ Repository Architecture

```text
Structured-Python/
│
├── 🧠 Foundations
│   └── Python Intro.ipynb                     # I/O, Data Types, Dynamic Memory & Functions
│
├── ⚙️ Data Structures & Algorithms
│   ├── Data_structures_in_Python.ipynb        # Lists, Tuples, Dictionaries & Operations
│   ├── Data_Structures_(Hashing_Sets).ipynb   # Hash Tables, Sets & Collision Resolution
│   ├── PDS_Stacks_and_Queues.ipynb            # LIFO Stacks & FIFO Queues Implementations
│   ├── Searching_Algorithms.ipynb             # Linear Search, Binary Search & Complexity
│   └── BFS_vs_DLF.ipynb                       # BFS & DFS Graph Traversal, Maze Solver & Pandas
│
├── 📊 Data Wrangling & Visual Analytics
│   └── Pandas_MAtplotlib_seaborn.ipynb        # DataFrames, Aggregations & Matplotlib Suite
│
├── 🔬 Applied Data Science & Machine Learning
│   ├── Practicals.ipynb                       # Loan Approval EDA & Categorical Encoding
│   └── LoanApprovalPrediction.csv             # Financial Domain Dataset
│
├── requirements.txt                           # Pinned Environment Dependencies
└── README.md                                  # Interactive Documentation Hub
```

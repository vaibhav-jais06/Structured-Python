## 📖 About The Project

Welcome to the **Structured-Python** repository! Whether you are writing your first line of code or brushing up on the basics, this project provides a structured, easy-to-follow, and interactive approach to learning Python. We focus on hands-on coding rather than just theory.

## 🎯 What's Inside?

We have structured the learning path into bite-sized, interactive chunks inside our Jupyter Notebook (`Python Intro.ipynb`). 

<details open>
  <summary><b>Click to expand the curriculum details!</b></summary>
  <br/>

| Module | Topic | Description |
| :---: | :--- | :--- |
| 🖨️ | **Warm-up & Printing** | Mastering the `print()` function and output formatting. |
| 🔢 | **Literals & Data Types** | Understanding integers, floats, strings, and booleans. |
| 📦 | **Variables** | Declaring and manipulating variables in memory. |
| ⌨️ | **User Input** | Interacting dynamically with users via `input()`. |
| ⚙️ | **Functions** | Defining custom logic, passing arguments, and modularizing code. |

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Make sure you have Python installed. We highly recommend using **Jupyter** to interact with the notebooks.

```bash
# Install Jupyter Notebook via pip
pip install notebook
```

### 🛠 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vaibhav-jais06/Structured-Python.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd Structured-Python
   ```
3. **Launch the learning environment:**
   ```bash
   jupyter notebook
   ```
   > 💡 **Pro Tip:** Once Jupyter opens in your browser, click on `Python Intro.ipynb` and press `Shift + Enter` to run the code cells interactively!
